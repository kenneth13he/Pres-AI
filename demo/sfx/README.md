# demo/sfx

Short royalty-free clips for the `distraction` curveball, served at `/demo/sfx/<name>.mp3`:

- `phone_ring.mp3`
- `door.mp3`

A cough and a sigh do not need clips: Higgs TTS 3 vocalises `<|sfx:cough|>` / `<|sfx:sigh|>` in a persona's voice (CLAUDE.md §13). Phone rings and door slams are not vocal, so they stay local.
